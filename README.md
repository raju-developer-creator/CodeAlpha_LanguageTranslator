# CodeAlpha_LanguageTranslator

Language translation tool built for the CodeAlpha AI Internship (Task 1).

## Features
- Source (with auto-detect) and target language selection
- Translation using the free MyMemory API
- Copy button, swap languages, text-to-speech
- Responsive, dark/light theme

## Run
Open `index.html` in a browser.

## Stack
HTML, CSS, JavaScript
